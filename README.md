# Aura Retail Smart Kiosk 🛒✨

[![Live Demo](https://img.shields.io/badge/Live_Demo-Click_Here-blue?style=for-the-badge&logo=render)](https://aura-retail-project.onrender.com/)

Welcome to the **Aura Retail Smart Kiosk** project! This is a comprehensive Object-Oriented Programming (OOP) project that simulates the backend software and operations of a modern, intelligent retail kiosk system. 

## 🌐 Live Demo
Check out the live simulation running here: **[Aura Retail Project Live](https://aura-retail-project.onrender.com/)**

## 🏗️ Architecture & Design Patterns
This project heavily emphasizes robust system architecture. It has been built implementing **13 key software design patterns** to ensure scalability, reliability, and maintainability.

The system handles:
- **Kiosk State Management** (Idle, Processing, Maintenance, etc.)
- **Inventory & Pricing Strategies**
- **Hardware Simulation** (Dispensers, Payment Processors)
- **Event-driven Architecture** (Event Bus, Central Registry)

## 🚀 Key Features
- **Multi-User Concurrency handling**
- **State-of-the-art Design Patterns Implementation**
- **Extensible Hardware and Event Managers**
- **Robust Persistence Management**

## 💻 Running Locally

### Prerequisites
- Python 3.x installed

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/devam1912/aura-retail-smart-kiosk.git
   cd aura-retail-smart-kiosk
   ```
2. Install the requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application/simulation:
   ```bash
   python app.py
   ```
